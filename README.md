# Шахматы для малышей

Простая игра в шахматы против компьютера для ребёнка, который только учится.
Чистые HTML + JavaScript, без сборки и зависимостей. Сайт лежит в папке `docs/`.

## Что умеет

- Играть с компьютером за белых или за чёрных (доска поворачивается).
- Режим «🧩 Сам за обоих» — ребёнок ходит и за белых, и за чёрных: решать задачи или играть вдвоём.
- Редактор позиции «✏️ Расставить»: палитра фигур, ластик, перетаскивание, выбор, чья очередь хода.
  Позицию можно вставить или скопировать в нотации FEN, ошибки в ней объясняются по-русски.
  Перед игрой позиция проверяется: по одному королю, нет пешек на крайних горизонталях, нет «лишнего» шаха.
- Три уровня компьютера:
  - 🐣 **Малыш** — ходит почти случайно, иногда что-нибудь съедает;
  - 🐰 **Новичок** — любит брать фигуры, но часто ошибается;
  - 🦊 **Хитрый** — смотрит на ход вперёд и не отдаёт фигуры даром.
- Помощники (можно выключить в «⚙️ Помощники»):
  - зелёным подсвечиваются фигуры, которые могут ходить;
  - при выборе фигуры точками показано, куда можно пойти, кольцом — кого можно съесть;
  - красная точка — туда можно, но там фигуру съедят; значок «!» — фигуру сейчас хотят съесть;
  - объяснение, как ходит выбранная фигура.
- Кнопки «Вернуть ход» и «Подсказка», шах подсвечивается красным.
- Все правила: рокировка, взятие на проходе, превращение пешки,
  мат, пат, ничья по материалу, правилу 50 ходов и троекратному повторению.
- Пешка, дошедшая до конца доски, превращается в фигуру на выбор: ферзь, ладья, слон или конь.
- Можно нажимать на клетки или перетаскивать фигуры — удобно и мышкой, и пальцем на планшете.

## Запуск локально

```sh
npm start          # или: python3 -m http.server 8000 --directory docs
```

и открыть http://localhost:8000.

## Тесты

```sh
npm test
```

Проверяют генератор ходов по эталонным значениям perft и играют партии компьютер против компьютера.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` при каждом пуше в `master` прогоняет тесты и публикует папку `docs/`.
Один раз нужно включить Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Адрес сайта: https://dimmik.github.io/chess/

## Файлы

- `docs/engine.js` — правила шахмат;
- `docs/ai.js` — компьютерный соперник;
- `docs/app.js` — интерфейс;
- `docs/pieces.js` — контуры фигур из шрифта DejaVu Sans.
